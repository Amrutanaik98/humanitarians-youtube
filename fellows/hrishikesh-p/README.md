## Frictional log

Each work folder contains a dated `FRICTIONAL.md` record of the process behind that
week's work: what was tried and expected, where it resisted and what was done next,
what Claude or another person contributed, what was accepted, changed, or rejected,
and what is now understood or still open. Append as you go; never rewrite an earlier
entry. It is not graded and not a performance review. See
<https://www.humanitarians.ai/fellows> for what an entry contains.
